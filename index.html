📝 Quick Setup Guide

  1. Go to Cloudflare Dashboard → Workers & Pages → Create a Worker
  2. Copy cms/worker.js into the worker editor and click Deploy
  3. Create a KV Namespace named PRODUCTS and bind it to the worker (variable name: PRODUCTS)
  4. Add environment variable ADMIN_TOKEN = any secret string you choose
  5. Set these env vars and run: node cms/import-to-kv.js to import all 154 products
  6. Paste your Worker URL and ADMIN_TOKEN above → Save Connection
  7. Reload this page — all 154 products appear ✓
